## ✨ Features

- **Interactive 3D Product Stage**: Floating products layered with dynamic background typography and smooth slide-out transitions.
- **Dynamic Colorways & Radial Lighting**: Instant mood and palette switching with matching spotlight gradients.
- **Audio Feedback**: Subtle, synthetic audio cues powered by the native browser Web Audio API.
- **Product Categories**:
  - 👟 **Footwear**: Nike Air Force 1 Low Retro Red
  - 👔 **Menswear**: Relaxed Linen & Pleated Trousers
  - 👗 **Womenswear**: Elegant Linen & Wide Silhouette Trousers
  - 💄 **Cosmetics**: Luxury Blush Palette & Brush
  - 🏋️ **Gym Gear**: Cast Iron Hex Weights
  - 🔮 **Accessories**: Jellyfish Crystal Glass Decor
- **Responsive & High Performance**: Built with Next.js Turbopack and Tailwind CSS for lightning-fast loads.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Audio:** Web Audio API (Synthesized Oscillators)
- **Deployment:** [Vercel](https://vercel.com/)

## 💻 Getting Started Locally

Clone the repository and install dependencies:

```bash
git clone https://github.com/aishikxai/velora-.git
cd velora-
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore the store.
